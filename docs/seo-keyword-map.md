## Rules

1. **One primary keyword per page.** If a new idea's keyword is already taken, either fold the content into the existing page or pick a genuinely different keyword.
2. Primary keyword goes in: `<title>`, `<h1>`, first paragraph, and the URL slug where natural.
3. Collections pages are the money pages — blog posts exist to feed them internal links.
4. No city/state landing pages (thin-content risk) — revisit only after collections rank.
5. Update this file in the same commit that adds any new page or post.
